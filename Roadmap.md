## In progress: modding tools

Built one milestone at a time, all on the **Modding tools** page (hidden unless you turn it on):

1. ~~`mod.json` format 1 and the Modding tools page~~ (done)
2. **Mod checker and packager:** check a mod for problems (protected files, whole game archives, files identical to the originals, PS3 files) and package it as a clean .zip. Plus drag-and-drop installs on the Mods page.
3. **Create mod from changes:** turn the files you edited into a mod automatically.
4. **Test this mod:** quick launch with just one mod enabled.
5. **File access log:** see which game files the game actually reads, to find what to mod.
6. **Archive browser:** look inside the game's `.big` (EB3) archives.
7. **Texture packs:** mods that change individual files inside the game's archives.

## Not planned

- **Multiplayer.** Networking is beyond the scope of this launcher. If someone builds multiplayer for the recomp, the launcher will probably add support for their tool.
